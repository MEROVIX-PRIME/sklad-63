# Сайт-магазин "Распродажа склада"

## Что внутри
- `index.html` — сама страница
- `style.css` — оформление
- `app.js` — вся логика (каталог, корзина, скидки, отправка заявки)
- `products.json` — 222 товара из вашего прайса (название, цена, остаток, фото, категория)
- `images/` — сжатые фото товаров (взяты прямо из ячеек вашего Excel-файла)

## Шаг 1 — подключите приём заявок (Formspree)

Сайт отправляет заявки через бесплатный сервис Formspree — письмо с заказом
будет приходить прямо вам на почту, без участия покупателя.

1. Зайдите на **https://formspree.io** → зарегистрируйтесь бесплатно (можно через email или Google).
2. Создайте новую форму (New Form), укажите почту **jaks8@list.ru** как адрес получателя.
3. Formspree выдаст ссылку вида `https://formspree.io/f/xxxxxxxx` — скопируйте её.
4. Откройте файл `app.js`, в самом начале найдите строку:
   ```js
   FORMSPREE_ENDPOINT: "https://formspree.io/f/YOUR_FORM_ID",
   ```
   Замените `YOUR_FORM_ID` на ваш реальный адрес формы.
5. **Важно:** на бесплатном тарифе Formspree первое письмо с каждой формы требует подтверждения — Formspree пришлёт вам письмо с просьбой подтвердить форму, нажмите там "Confirm". После этого всё будет приходить автоматически.

## Шаг 2 — настройте живые остатки (Google-таблица)

Чтобы остатки на сайте обновлялись, когда вы меняете их вручную (после
подтверждения заказа), нужно один раз настроить Google-таблицу как
источник данных:

1. Зайдите на **https://sheets.google.com** → создайте новую пустую таблицу.
2. Файл → Импорт → Загрузить → выберите файл **`google_sheet_import.csv`** из этой папки → "Заменить текущий лист" → Импортировать данные.
   В таблице появятся столбцы: `ID`, `Товар`, `Цена`, `Остаток` — уже заполненные из вашего прайса.
3. **Важно:** не удаляйте и не меняйте местами столбцы `ID`, `Цена`, `Остаток` — именно по их названиям сайт находит нужные данные. Столбец `Товар` можно оставить просто для вашего удобства (сайт его не читает).
4. Файл → Общий доступ → Опубликовать в интернете (Share → Publish to web).
5. Выберите текущий лист, формат **CSV**, нажмите "Опубликовать".
6. Скопируйте выданную ссылку (заканчивается на `output=csv`).
7. Откройте `app.js`, найдите строку:
   ```js
   STOCK_SHEET_CSV_URL: "",
   ```
   Вставьте скопированную ссылку между кавычками.

**Как это работает дальше:** когда покупатель заходит на сайт, тот
подтягивает свежие цену и остаток из этой таблицы поверх обычных карточек.
Когда вы подтвердили заказ с покупателем — просто откройте таблицу и
вручную уменьшите число в столбце `Остаток` для купленных позиций.
Изменения на сайте появятся при следующей загрузке страницы (обычно
сразу, иногда через 1-2 минуты — так работает публикация Google).

Если строка `STOCK_SHEET_CSV_URL` остаётся пустой — сайт продолжает
работать на исходных данных из `products.json`, ничего не сломается.

## Кнопка "Скачать прайс"

Наверху сайта есть кнопка — она формирует Excel-файл прямо в браузере
посетителя, с теми же колонками, что и в вашем исходном прайсе (все фото
/ фото / количество / Товар / цена / Заказ / сумма), но с **живыми**
остатками и ценами (если вы настроили Google-таблицу по шагу выше).

Один нюанс: в отличие от вашего файла, где фото вставлены прямо в ячейки,
здесь в колонках "все фото" и "фото" — кликабельные ссылки (открывают
фото на сайте). Настоящие вставленные картинки надёжно сгенерировать
прямо в браузере не получится — ссылка на фото удобнее и стабильнее.

## Шаг 3 — проверьте сайт локально (не обязательно, но полезно)

Открыть `index.html` двойным кликом не получится — браузер заблокирует
загрузку `products.json` из соображений безопасности. Нужен локальный сервер:

**Если есть Python:**
```
cd путь-до-папки-с-сайтом
python -m http.server 8000
```
Затем откройте в браузере `http://localhost:8000`

Либо просто переходите сразу к шагу 3 — там всё будет работать без этой возни.

## Шаг 4 — разместите сайт в интернете

Самый простой бесплатный способ — **Netlify Drop**:

1. Зайдите на **https://app.netlify.com/drop**
2. Перетащите ВСЮ папку с сайтом (index.html, style.css, app.js, products.json, images/) в окно браузера
3. Через несколько секунд Netlify выдаст рабочую ссылку на ваш сайт — готово

Если у вас уже есть свой хостинг/домен — просто загрузите все файлы (сохраняя структуру папок) через файловый менеджер хостинга или FTP.

## Как изменить остальные настройки

Все основные параметры (телефон, email, минимальная сумма заказа, пороги
скидок, список транспортных компаний) собраны в начале файла `app.js`, в
блоке `CONFIG` — их можно менять текстом, без знания программирования,
просто открыв файл в блокноте.

## Как обновить остатки/цены в будущем

Отдельного личного кабинета для редактирования на сайте нет — если нужно
обновить цены, остатки или добавить/убрать товары, пришлите мне
обновлённый прайс, и я пересоберу `products.json`.

## Товары без указанного количества

3 позиции в исходном прайсе были без указанного остатка — на сайте они
показаны с пометкой "Уточнить наличие" и доступны к заказу без ограничения
по количеству (это можно поменять в `products.json` вручную, если нужно).
